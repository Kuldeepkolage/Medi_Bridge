# 🦷 MediBridge Dental Clinic

A full-stack MERN dental clinic management system built to streamline patient appointments, emergency requests, reviews, and clinic administration.

## 🚀 Features

### 👨‍⚕️ Patient Features

* User Registration & Login
* Book Dental Appointments
* View Appointment History
* Emergency Request Submission
* Ratings & Reviews
* Multi-Language Support (English, Hindi, Marathi)
* Profile Management

### 🛠️ Admin Features

* Admin Dashboard
* Appointment Management
* Approve / Reject Bookings
* Patient Management
* Review Moderation
* Emergency Request Monitoring
* Analytics & Statistics

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Kuldeepkolage/Medi_Bridge.git
cd Medi_Bridge
```

### Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret
```
